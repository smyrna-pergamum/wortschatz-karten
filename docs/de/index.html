02 · LEITNER-SYSTEM

Jedes Wort kommt zur richtigen Zeit zurück.

Richtig beantwortete Karten wandern in die nächste Box, der Abstand wird größer. Falsch beantwortete kommen zurück in Box 1 und am selben Tag noch einmal dran. Klick auf eine Box!

Box 1 · Erster Schritt

Nach einer richtigen Antwort kommt die erste Wiederholung nach 1 Tag. Falsch beantwortete Karten kommen heute noch einmal.

Alles, was du von der Installation bis zur ersten Wiederholungsrunde brauchst. Die App ist auf Deutsch — die Menünamen stehen hier im Original.

  1. 1

    Herunterladen

    Lade WortschatzKarten_Setup.exe aus der neuesten Version auf GitHub herunter.

    Zur neuesten Version ↗
  2. 2

    Installieren

    Starte das Setup. Die App wird unter Program Files installiert (Administratorrechte nötig), mit Startmenü-Eintrag und Deinstallationsprogramm.

  3. 3

    Liste importieren

    Beim ersten Start findet die App die mitgelieferte Wortliste und fragt, ob sie importiert werden soll. Klick auf Ja — 1.436 Wörter sind bereit.

  4. 4

    Karte umdrehen

    Sieh dir das Wort an, versuche dich an die Bedeutung zu erinnern, und dreh die Karte mit Space um.

    Antworten

    2 „gewusst“, 1 „nicht gewusst“. Das Leitner-System legt die Karte in die richtige Box und bringt sie zur richtigen Zeit zurück.

05 · HÄUFIGE FRAGEN

Bevor du loslegst.

Eine eher technische Frage?
Zur Projektdokumentation ↗

Für wen ist die App?

Für alle, die Deutsch lernen — von A1 bis C1 — und für alle, die sich auf die DSH vorbereiten. Die mitgelieferte Liste enthält den DSH-Wortschatz; mit deiner eigenen Excel-Liste lernst du auf jedem Niveau. Die Oberfläche der App ist auf Deutsch.

Ist sie wirklich kostenlos?

Ja. Wortschatz Karten ist kostenlos und Open Source unter der MIT-Lizenz. Den Quellcode findest du auf GitHub. Ein Konto brauchst du nicht.

Auf welchen Geräten läuft sie?

Das Setup ist für Windows 10 und Windows 11 (64 Bit). Die Karte auf dieser Seite ist nur ein Beispiel; die vollständige App wird unter Windows installiert.

Brauche ich Internet?

Karteikarten und Lernfortschritt funktionieren offline. Nur die optionale Übersetzung und die Online-Aussprache brauchen Internet; Ergebnisse werden zwischengespeichert. Für die Übersetzung werden das deutsche Wort und der Beispielsatz an Google Translate gesendet (Sätze notfalls an MyMemory), für die Online-Aussprache das Wort an Googles Sprachdienst. Mit einer deutschen Windows-Stimme klappt die Aussprache auch offline.

Kann ich eigene Wörter hinzufügen?

Ja. Über Daten → Excel aktualisieren… importierst du deine Excel-Datei (.xlsx). Nur die Wortspalte ist Pflicht; Erklärung, Übersetzung, Synonyme, Antonyme und Beispielsätze sind optional. Beispieldatei herunterladen. Die Spalten findest du im Excel-Abschnitt.

Wie installiere ich die App?

Der Download-Knopf führt zur neuesten Version auf GitHub. Lade dort WortschatzKarten_Setup.exe herunter und folge dem Setup (Administratorrechte nötig). Bestätige beim ersten Start den Import der Wortliste. Schritt für Schritt: Anleitung.
