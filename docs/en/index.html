03 · USER GUIDE

Five steps to your first card!

Everything you need from installing to your first review round. The app’s interface is in German, so menu names are given in German below.

  1. 1

    Download

    Download WortschatzKarten_Setup.exe from the latest release on GitHub.

    Go to latest release ↗
  2. 2

    Install

    Run the installer. It installs to Program Files (administrator rights required) and adds a Start menu entry and an uninstaller.

  3. 3

    Import the list

    On first start the app finds the included word list and asks whether to import it. Click Yes — 1,436 words are ready.

  4. 4

    Flip the card

    Look at the word, try to recall its meaning, then press Space to flip the card.

  5. 5

    Answer

    2 “known”, 1 “not known”. The Leitner system puts the card in the right box and brings it back at the right time.

!

If Windows warns you: the installer is not code-signed yet, so SmartScreen may warn about an unknown publisher: More info → Run anyway. You can check the download against the SHA-256 checksum in the release notes.

05 · FREQUENTLY ASKED

Before you start.

A more technical question?
Read the project docs ↗

Who is the app for?

For anyone learning German — from A1 to C1 — and for students preparing for the DSH. The included list covers DSH vocabulary; with your own Excel list you can study at any level. The app’s interface is in German.

Is it really free?

Yes. Wortschatz Karten is free and open source under the MIT license. The source code is on GitHub. No account is needed.

Which devices does it run on?

The installer is for Windows 10 and Windows 11, 64-bit. The card on this page is only a demo; the full app is installed on Windows.

Do I need an internet connection?

Flashcards and progress tracking work offline. The optional translation and online pronunciation need internet; results are cached. For translation, the German word and example sentence are sent to Google Translate (sentences fall back to MyMemory); for online pronunciation, the word is sent to Google’s text-to-speech service. With a German Windows voice, pronunciation also works offline.

Can I add my own words?

Yes. Use Daten → Excel aktualisieren… to import your Excel (.xlsx) file. Only the word column is required; explanation, translation, synonyms, antonyms and example sentences are optional. Download the sample file. The column list is in the Excel section.

How do I install it?

The download button takes you to the latest release on GitHub. Download WortschatzKarten_Setup.exe and follow the installer (administrator rights required). On first start, accept the offer to import the word list. Step by step: user guide.
